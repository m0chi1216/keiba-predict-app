# 学習側testデータの除外ルール監査

2026-10-11。対象は隣接学習プロジェクトのdata/learn_data/learn_data_jsp.csv、2025-12-31より後のtest期間とsrc/neural/data.py。ユーザー質問に対し検査と実データを照合した。モデル・検査ルールは変更していない。

実測: 2,331レース・19,335行のうち2,191レース・17,621行を除外。最大理由はCSV行数とnum_of_horseの不一致2,184（少ない2,176、多い8）。頭数欠損・不正・レース内不一致は0。非数値着順124レース133行（中58、除57、取18）。勝ち馬数不一致394（1着なし392、複数1着2）。理由は重複。ID/馬番、日付、勝ち馬払戻の不正による除外は0。

現在の検査は1頭だけを除くのでなく、問題があるレース全体を除外する。例：race_id202601010104は頭数14に対しCSV10行で、勝ち馬はあるが全頭が揃っていない。50倍上限は検査後の購入条件であり、このレース除外とは別。

必要列だけ再読込・test抽出・race_idごと再集計し、主要件数が元data_report.jsonと一致することをassertで検証した。保存は学習側data/simulation/neural/20261011_regression_jsp_max50_rank_search/exclusion_audit_20261011/のsummary.jsonとrace_checks.csv。詳細・再集計方法は学習側.agents/docs/2026-10-11-test-data-exclusion-audit.md。欠落行の根本原因や学習・検証期間は今回未調査。
