# 学習側の回帰testシミュレーション（50倍上限）

2026-10-11。対象モデルは隣接学習プロジェクトのmodels/race_model/20261011_regression_jsp、データはdata/learn_data/learn_data_jsp.csv。検証末2025-12-31より後を抽出し、既存検査通過140レース（2026-01-04〜09-27）をCUDAで再推論。各レース予測値最小の馬を選び、50倍超なら見送る。次点に置換しない。単勝100円、実払戻列なしのためods×100による概算。

実測: 制限なし参考140件21的中、的中率15.00%、回収率65.79%。50倍以下の全購入は131件21的中、16.03%、70.31%、-3,890円。正規化着順しきい値<=0.30179518461227417で最高回収率173.33%（9件4的中、44.44%、+660円）。参考として30件以上購入する制約では<=0.3644530475139618が最高83.95%（38件9的中、23.68%、-610円）。全131境界を比較。

test元データ2,331レースのうち完全レース等の検査通過は140、2,191除外。理由重複あり。しきい値はユーザー指定によりtest結果で選択し、独立評価ではない。最高条件は9件のみで、1件の払戻が総払戻の55.13%を占める。将来回収率を示すものではない。

src/evaluation/simulate_neural.pyと4テストを追加。4テスト成功（0.012秒）。学習保存済み140件と選択馬・払戻一致、予測差1e-7以内、131境界と最良2明細を独立再集計して一致を確認。本予測アプリのコード・モデルは変更していない。

保存先は学習側data/simulation/neural/20261011_regression_jsp_max50_rank_search/。summary.json、全境界CSV、購入明細、除外レポートを保存した。詳細は学習側.agents/docs/2026-10-11-neural-test-simulation-max50.md。再実行は学習側ルートから `uv run python -m src.evaluation.simulate_neural --model models/race_model/20261011_regression_jsp --output data/simulation/neural/20261011_regression_jsp_max50_rank_search_r02 --max-odds 50 --min-bets 30`。出力先は空の新規ディレクトリを指定する。
